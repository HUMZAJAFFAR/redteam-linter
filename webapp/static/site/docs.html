Install

Requires Python 3.9 or newer. rich and PyYAML power the terminal report and the rule loader; FastAPI and uvicorn are only needed for the console.

git clone https://github.com/HUMZAJAFFAR/redteam-linter.git
cd redteam-linter
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt

On Windows, activate with .venv\Scripts\activate. Nothing is installed globally.

Usage

Start the server, then open the console and click Load sample for a known-vulnerable fixture.

.venv/bin/python -m uvicorn webapp.server:app --port 8000
# console: http://127.0.0.1:8000/app
# site:    http://127.0.0.1:8000/

Python API

The console is a thin layer over the same engine the CLI uses. Import it directly when you want findings in your own pipeline.

from webapp.engine import scan_files
from reporter import ReportGenerator
from config_loader import load_sink_config

findings, scanned, skipped = scan_files(
    [{"path": "target.py", "content": source}],
    load_sink_config("sinks.yaml"),
)

generator = ReportGenerator(findings, files_scanned=len(scanned))
generator.print_report()
generator.export_to_json("redteam-report.json")

The console

Four working views, behind a hash router:

ViewPurpose
#/scanPaste code or drop up to 25 files (2 MB total), run the scan, read the summary tiles.
#/findingsFilter by severity, triage status and text; group by file or severity; open any finding.
#/rulesThe sink table currently loaded, with its source (sinks.yaml or the built-in fallback).
#/assistantAsk about a finding or about the tool; answers come from a local catalogue unless a key is configured.

Triage status is stored in localStorage under redteam.triage.v1, keyed by file:line:sink. Notifications live under redteam.notif.v1. The server keeps no state.

Rule schema

Sinks are declared in sinks.yaml. Only name is required; import aliases are resolved by the analyzer, so write the canonical dotted name once.

sinks:
  - name: "subprocess.call"
    category: "RCE"
    requires_shell_true: true
    description: "Safe with a list and shell=False."
KeyMeaning
nameCallable as written in source, or a bare name like eval.
categoryFree-form taint family shown in the report.
requires_shell_trueOnly flag the call when shell=True is present.
severity, descriptionOptional annotations carried through untouched.

If the file is missing or invalid, the built-in table is used and the Rules view reports a fallback. Validate after editing: python -c "import yaml; yaml.safe_load(open('sinks.yaml'))".

Redaction

Redaction is output-side and happens exactly once, in reporter.ReportGenerator. The engine keeps the original bytes in memory so taint analysis can still reason about them.

  • Evidence keeps its first four characters: AKIA***REDACTED***.
  • Source excerpts mask the value, not the line: DB_PASSWORD = "<redacted>".
  • arguments_passed stays intact — it is the taint bridge, not credential material.
  • The reporter re-scrubs excerpt text, so a credential the engine missed still cannot reach the page.
  • Clipboard, export and devtools all see the same redacted structure.

HTTP API

MethodPathPurpose
GET/api/healthEngine, version, rule count, rule source.
GET/api/rulesActive sink rules.
POST/api/scanScan documents, return the redacted payload.
POST/api/reportScan and download the redacted JSON report.
GET/api/assistant/statusLocal or model mode, never the key.
POST/api/assistantAnswer a question, optionally with a finding summary.
 
curl -s -X POST http://127.0.0.1:8000/api/scan \
  -H 'Content-Type: application/json' \
  -d '{"files":[{"path":"target.py","content":"import os\nos.system(cmd)\n"}]}'

Response shape: {"summary": {...}, "findings": [...], "meta": {...}}. Limits: 25 files, 2 MB total. Errors: 422 empty payload, 413 oversized, 403 cross-origin, 429 rate limited.

Security

  • Strict CSP with no inline script or style; nosniff, no referrer, COOP/CORP, restrictive permissions policy.
  • Cross-origin state-changing requests are rejected with 403; API responses are no-store.
  • Bodies over REDTEAM_MAX_BODY_BYTES (2.5 MB) are rejected before buffering, chunked uploads included.
  • Per-client rate limits: assistant 20/min, scan 40/min, report 20/min, /api 120/min.
  • No authentication: bind to 127.0.0.1 and keep it off untrusted networks.

Full threat model and disclosure policy: /security.

Troubleshooting

The scan returns 413

The payload exceeded 2 MB or the request body cap. Split the upload or scan fewer files.

Repeated 429 responses

Rate limits are per client and per route. Wait for the window to reset; the response carries Retry-After.

403 cross-origin request blocked

The Origin header did not match the host. Call the API from the same origin as the console.

The assistant badge says “local”

No model key is configured. Set REDTEAM_AI_KEY (optionally REDTEAM_AI_BASE and REDTEAM_AI_MODEL) and restart. Local mode is fully functional without it.

Port already in use

Start uvicorn with a different --port, or stop the previous instance.
