    How this works

    • AST, not grep. Only real call sites match, so comments and strings cannot produce noise.
    • Aliases resolved. from os import system as sh still matches os.system.
    • Redacted twice. The engine masks values, then the reporter scrubs every text field again.
    • No state. Your code is parsed in memory and discarded with the request.

    Rules are read from sinks.yaml; the Rules view shows exactly what is loaded.
