    Usage

    Start the console, then paste code or drop Python files and run the scan. The CLI-equivalent path is the Python API below.

    .venv/bin/python -m uvicorn webapp.server:app --port 8000
# then open http://127.0.0.1:8000

    Python API

    from webapp.engine import scan_files
from reporter import ReportGenerator
from config_loader import load_sink_config

findings, scanned, _ = scan_files(
    [{"path": "target.py", "content": source}],
    load_sink_config("sinks.yaml"),
)
generator = ReportGenerator(findings, files_scanned=len(scanned))
generator.print_report()
generator.export_to_json("redteam-report.json")

    Rules

    Sinks are declared in sinks.yaml. Only name is required; import aliases are resolved by the analyzer, so write the canonical dotted name once.

    sinks:
  - name: "subprocess.call"
    category: "RCE"
    requires_shell_true: true
    description: "Safe with a list and shell=False."
    KeyMeaning
    nameCallable as written in source, or a bare name like eval.
    categoryFree-form taint family shown in the report.
    requires_shell_trueOnly flag the call when shell=True is passed.
    severity, descriptionOptional annotations carried through to the report.

    If the file is missing or invalid the built-in table is used instead, and the Rules view reports it as a fallback. Validate after editing with python -c "import yaml; yaml.safe_load(open('sinks.yaml'))".

    Redaction

    • Redaction is output-side and happens once, in reporter.ReportGenerator.
    • Evidence keeps its first four characters only: AKIA***REDACTED***.
    • Source excerpts mask the value, not the line, so DB_PASSWORD = "<redacted>" stays readable.
    • arguments_passed is intentionally intact — it is the taint-analysis bridge, not credential material.
    • The browser, the clipboard and the exported report all receive the same redacted structure.

    HTTP API

    MethodPathPurpose
    GET/api/healthEngine, version, rule count and rule source.
    GET/api/rulesActive sink rules.
    POST/api/scanScan documents, return the redacted payload.
    POST/api/reportScan and download the redacted JSON report.
    GET/api/assistant/statusLocal or model mode, never the key.
    POST/api/assistantAnswer a question, optionally with a finding.

    Payload: {"files": [{"path": "target.py", "content": "..."}]}. Limits: 25 files, 2 MB total; 422 empty, 413 oversized, 403 cross-origin, 429 rate limited.

    Security

    • Strict CSP with no inline script or style, plus nosniff, no referrer and COOP/CORP.
    • Cross-origin state-changing requests are rejected with 403; API responses are no-store.
    • Request bodies over 2.5 MB are rejected before buffering, including chunked uploads.
    • Per-client rate limits: assistant 20/min, scan 40/min, report 20/min, /api 120/min.
    • The console has no authentication — keep it bound to 127.0.0.1.

    Environment knobs: REDTEAM_MAX_BODY_BYTES, REDTEAM_FRAME_ANCESTORS, and the assistant variables below.

    Troubleshooting

    413 Payload too largeTrim the upload below 2 MB or split the files.
    429 Rate limit exceededWait for the window to reset; limits are per client and per route.
    403 Cross-origin request blockedThe Origin header did not match the host; call the API from the same origin.
    Assistant badge says localNo API key is configured. Set REDTEAM_AI_KEY, optionally REDTEAM_AI_BASE and REDTEAM_AI_MODEL, then restart.
    Port already in useStart uvicorn with a different --port, or stop the previous instance.
