Security model

A tool that finds secrets should not leak them.

The console is a local review tool. It assumes the code you scan may be hostile and the browser you scan from may have other tabs open. This page lists what that assumption costs and what is actually implemented.

Threat model

Four things worth defending against.

Another page driving the tool

A malicious tab could POST a scan or export your findings if the API accepted cross-origin writes. Mitigated by JSON-only bodies, an Origin/Host check and a CSP that forbids framing.

Payload exhaustion

A 500 MB upload would otherwise be buffered before validation. The body cap rejects oversized requests before they are read, including chunked bodies without a length header.

Data becoming script

Findings contain attacker-controlled source text. Every value is rendered with textContent or DOM builders, and the CSP forbids inline script and style, so a snippet cannot become markup or code.

The secret escaping

The whole point is to find credentials without exfiltrating them. Redaction is enforced in one place and applied again to source excerpts; the assistant never receives snippets or secret values.

Controls

What is actually in the code.

ControlImplementation
Strict CSPdefault-src 'self', no inline script or style, no objects, base-uri 'none', form-action 'none'.
MIME sniffingX-Content-Type-Options: nosniff on every response.
Clickjackingframe-ancestors 'self', widenable only via REDTEAM_FRAME_ANCESTORS.
Cross-origin writesOrigin must match Host for state-changing methods, otherwise 403.
Body size2.5 MB cap enforced before buffering, streaming-aware.
AbuseSliding-window limits per client and route, 429 with Retry-After.
CachingCache-Control: no-store on every /api response.
API surface/docs, /redoc and /openapi.json disabled; server header suppressed.
SecretsRedaction in the reporter, a second scrub pass on excerpts, and an eight-field whitelist for the assistant.
PathsSubmitted paths normalised, .. stripped, .py enforced, duplicates suffixed.
StorageThe browser stores triage status and notification text only — no code, no findings.

Disclosure

Found something?

Please open a private security advisory on the repository rather than a public issue, and include the version from /api/health, the request that triggers it and the impact you believe it has.
